# บัญชีขนมบ้านเพลง

แอปบัญชีรายรับ-รายจ่ายของร้านขนมบ้านเพลง-พระแท่น ติดตั้งลงมือถือได้ (PWA) และใช้งานได้แม้ไม่มีอินเทอร์เน็ต

- เปิดแอป: https://worrapojs28-hash.github.io/baanpleng-books/
- ข้อมูลเก็บใน Firebase Firestore ของร้าน ป้องกันด้วย `firestore.rules`
- โค้ดใน repo นี้เปิดเผยได้ ไม่มีข้อมูลบัญชีหรือรหัสผ่านอยู่ในโค้ด

## ติดตั้งลงมือถือ
- **iPhone:** เปิดลิงก์ใน Safari → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
- **Android:** เปิดลิงก์ใน Chrome → เมนู ⋮ → "ติดตั้งแอป" หรือ "เพิ่มลงในหน้าจอหลัก"

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `styles.css`, `app.js` | ตัวแอป |
| `firebase-config.js` | ค่าเชื่อมต่อ Firebase (เปิดเผยได้) |
| `firestore.rules` | กฎความปลอดภัย วางใน Firebase Console > Firestore > Rules |
| `sw.js`, `manifest.webmanifest`, `icons/` | ทำให้ติดตั้งได้และเปิดได้ตอนออฟไลน์ |

## โครงสร้างข้อมูล (Firestore)
| คอลเลกชัน | เนื้อหา |
|---|---|
| `days/{YYYY-MM-DD}` | รายการบัญชีของวันนั้น (`entries`) |
| `meta/settings` | ชื่อร้าน บัญชีเงิน หมวด ยอดตั้งต้น เดือนที่ปิดงวด |
| `meta/owner` | เจ้าของร้าน |
| `members/{uid}` | ผู้ใช้งานและสิทธิ์ (owner / staff) |
| `invites/{email}` | คำเชิญพนักงาน |
| `contacts/{id}` | ลูกค้าและเจ้าหนี้ |
| `receipts/{id}` | รูปใบเสร็จ (ย่อขนาดแล้ว) |
| `audit/{id}` | ประวัติการแก้ไข เพิ่มได้อย่างเดียว |

## อัปเดตแอป
แก้ไฟล์แล้ว push ขึ้น `main` และเปลี่ยน `VERSION` ใน `sw.js` ทุกครั้ง มือถือจะได้เวอร์ชันใหม่เมื่อเปิดแอปครั้งถัดไป
